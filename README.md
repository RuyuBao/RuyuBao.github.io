# RuyuBao — CSI205 Student Homepage

A responsive, English-language student homepage built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, typography, and responsive design
- `main.js` — mobile navigation and automatic footer year

## Preview locally
Open `index.html` in a browser. For a more realistic local preview, use VS Code's Live Server extension.
