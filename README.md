# RuyuBao — CSI205 Student Homepage

A responsive, English-language student homepage built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, typography, and responsive design
- `main.js` — mobile navigation and automatic footer year

## Preview locally
Open `index.html` in a browser. For a more realistic local preview, use VS Code's Live Server extension.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, and `main.js` to the repository root (not inside another folder), then commit the changes.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Visit `https://YOUR-USERNAME.github.io/`.

If the site does not appear immediately, wait a few minutes and check the **Actions** tab and **Settings → Pages** for deployment status.

## Personalize
The page only uses details provided by RuyuBao. If you want, edit the wording in `index.html`, and change the color variables at the top of `style.css`.
